## 摘要
文本条件的三维生成在图像和孤立的物体上已取得快速进展，但生成手-物体网格仍具挑战性：输出必须保留语言语义、跨视角一致性、物体几何、关节化的手部形状以及物理上合理的接触。我们提出了 TextHOI-3D，一个分阶段框架，利用生成的多视角观测作为文本条件视觉生成与几何感知手-物体恢复之间的显式接口。TextHOI-3D 为固定摄像机的手-物体观测学习紧凑的 VQ 令牌空间，通过 CLIP 条件的视觉自回归模型从文本预测多视角视觉令牌，并通过先验初始化、多视角联合优化和防穿透细化恢复统一的手-物体网格。该设计将语义生成与几何恢复分离，同时通过离散多视角表示保持两个阶段相连。在基于 HO3D 的评估中，与单视角对应方案相比，多视角设置将物体倒角距离从 17.26 毫米降至 4.92 毫米，穿透体积从 5.3721 立方厘米降至 0.2193 立方厘米，同时改善了手部误差和表面 F 分数。这些结果支持多视角视觉令牌作为文本驱动 3D 手-物体网格创建的有效中间表示。

## Abstract
Text-conditioned 3D generation has progressed rapidly for images and isolated objects, but producing a hand-object mesh remains challenging: the output must preserve language semantics, cross-view consistency, object geometry, articulated hand shape, and physically plausible contact. We present TextHOI-3D, a staged framework that uses generated multi-view observations as an explicit interface between text-conditioned visual generation and geometry-aware hand-object recovery. TextHOI-3D learns a compact VQ token space for fixed-camera hand-object observations, predicts multi-view visual tokens from text with a CLIP-conditioned visual autoregressive model, and recovers a unified hand-object mesh through prior initialization, multi-view joint optimization, and anti-penetration refinement. The design separates semantic generation from geometric recovery while keeping both stages connected by a discrete multi-view representation. On HO3D-derived evaluations, the multi-view setting reduces object CD from 17.26 mm to 4.92 mm and penetration volume from 5.3721 cm^3 to 0.2193 cm^3 compared with a single-view counterpart, while improving hand errors and surface F-scores. These results support multi-view visual tokens as an effective intermediate representation for text-driven 3D hand-object mesh creation.

## 1. 核心问题与研究动机
- **任务**：给定一段文本描述（如“一只手握住杯子”），直接生成一个带有手部关节和物体的统一三维网格。
- **挑战**：该任务需要同时满足多项强约束——语言语义正确性、多视角一致性、物体几何合理、手部关节解剖学有效及物理接触（无穿透或漂浮）。
- **数据缺口**：带有文本‑网格配对的手‑物交互数据极为稀缺，而接触区域常被遮挡，使得端到端的文本‑到‑网格生成难以训练。
- **研究定位**：提出将问题**解耦**为文本→多视图图像→三维网格的两阶段范式，并引入**离散多视图视觉令牌**作为连接语义生成与几何恢复的紧凑中间表征。

## 2. 方法论
### 2.1 总体框架
TextHOI‑3D 由三个技术阶段构成：
1. **离散多视图表征学习**（VQ‑VAE）：将固定机位拍摄的多视图手‑物图像编码为离散令牌。
2. **文本条件多视图生成**（VAR + CLIP）：用文本控制自回归模型，逐尺度预测多视图令牌图。
3. **手‑物网格恢复**：从生成的多视图图像出发，通过先验初始化、多视图联合优化和防穿模后处理输出统一网格。

### 2.2 离散多视图视觉表征
- **视图组织**：将同一场景的 N 张 RGB 视图沿通道维堆叠，形成张量 \(\mathbf{X}\in\mathbb{R}^{H\times W\times 3N}\)，让编码器直接学习跨视图统计关联。
- **VQ‑VAE 架构**：编码器-码本-解码器结构，最高分辨率令牌图为 \(16\times16\)，码本大小 \(K=4096\)，每个码向量维度 32。
- **训练目标**：重建损失 + 承诺损失，即：
  \[
  \mathcal{L}_{VQ} = \|\mathbf{X} - \hat{\mathbf{X}}\|_2^2 + \|\text{sg}[\mathbf{z}_e] - \mathbf{z}_q\|_2^2 + \beta\|\mathbf{z}_e - \text{sg}[\mathbf{z}_q]\|_2^2
  \]
- **效果**：每个令牌对应一个多视图场景单元，而非单一视角图块，为生成提供紧凑且一致的中间空间。

### 2.3 文本条件多视图生成
- **采用范式**：基于 VAR 的**下一尺度预测**，逐步由粗到精地生成令牌图 \(p(\mathbf{R}\mid y)=\prod_{k=1}^K p(\mathbf{r}_k \mid \mathbf{r}_{<k}, y)\)。
- **文本注入机制**：
  - **全局调制**（AdaLN）：用 CLIP 的全局池化特征 \(\mathbf{c}_g\) 对隐藏状态进行缩放和平移。
  - **局部交叉注意力**：将 CLIP 的令牌级序列 \(\mathbf{c}_{seq}\) 作为 Key-Value，传入视觉 Transformer 块的交叉注意力层，以对齐物体局部属性（如把手、握持线索）。
- **训练与推理**：采用 Teacher‑Forcing 训练，推理时使用无分类器引导及 top‑k/top‑p 采样，最终冻结的解码器将令牌图映射回多视图图像。

### 2.4 手‑物网格恢复流水线
- **图像预处理**：
  1. **HSV 分割**：利用合成/渲染图像稳定的颜色分布，提取手部和物体掩膜。
  2. **双分支修补**：使用 Stable Diffusion LoRA 分别补全被物体遮挡的手部区域和被手部遮挡的物体区域。
- **先验初始化**：
  - **物体分支**：将修补后的物体多视图输入 InstantMesh，获得初始物体网格。
  - **手部分支**：结合 OmniHands 风格手部先验和 MANO 参数化模型，恢复手部网格及姿态。
- **多视图联合优化**：
  - 优化变量 \(\Xi = \{\Theta^h, \mathbf{T}^h, \mathbf{R}^o, \mathbf{t}^o, \Delta\mathbf{M}^o\}\)（手参数、手变换、物体刚体姿态、物体轻量形变校正）。
  - 总损失：\(\lambda_{mv}\mathcal{L}_{mv} + \lambda_c\mathcal{L}_{contact} + \lambda_p\mathcal{L}_{pen} + \lambda_r\mathcal{L}_{reg}\)。
    - \(\mathcal{L}_{mv}\)：多视图重投影与掩膜一致性。
    - \(\mathcal{L}_{contact}\)、\(\mathcal{L}_{pen}\)：鼓励接触邻近、惩罚穿透（利用手部接触候选区与物体 SDF）。
- **分阶段优化**：全局对齐 → 交互校正 → 局部精细优化 + 防穿插后处理。

## 6. 主要结论与发现
- **多视图令牌是有效的中间表征**：它能压缩手‑物场景信息，使生成器关注场景一致性，同时为恢复阶段提供丰富的几何线索。
- **多视图证据显著提升恢复质量**：物体 CD 从 17.26 mm 降至 4.92 mm，F@5 从 46.3% 升至 92.7%；手部 MPJPE 从 1.46 mm 降至 0.65 mm；穿透体积从 5.3721 cm³ 降至 0.2193 cm³。
- **解耦设计具有诊断优势**：生成、分割、修补、恢复各阶段可独立分析，便于定位失败原因。
- **接触与穿透精细控制可行**：优化和防穿透后能保持浅穿透深度和一定接触比例，而非简单分离手与物体。

## 7. 优点
- **创新性的分阶段范式**：将复杂的文本‑到‑手‑物网格任务拆解为可管理的子问题，并利用离散令牌桥接语义与几何。
- **紧凑且协同的表示**：堆叠多视图编码让 VQ‑VAE 自动捕获跨视图相关性，一个令牌即可表达全局场景单元。
- **文本注入机制精巧**：AdaLN 全局调制 + 交叉注意局部对齐，兼顾整体语义和局部细节。
- **恢复流水线完善**：结合分割、修补、先验模型、多视图联合优化与防穿透处理，形成一套完整的后处理方案，消融实验证明多视图输入的关键作用。
- **严格控制的消融实验**：唯一变量是视角数量，结果可信度高。
