## 摘要
我们推出了Home3D 1.0，这是一个模块化的图像到3D生成系统，能够从单张参考图像生成高质量的3D资产，主要面向室内设计和电商应用。给定家具或装饰品的照片，系统会输出带有基于物理渲染（PBR）材质的网格，且网格可分解为特定材质的组件。整个流程由四个紧密耦合的模块组成：几何模块通过隐式SDF建模，结合几何VAE和由粗到精的流匹配DiT，重建出水密网格；纹理模块预测多视角反照率观测，将其重投影到网格上，并利用3D纹理场补全不可见表面区域；材质模块使用MatWeaver，通过基于视频的分割和UV空间投票获取组件掩码，然后通过分层多模态匹配从精选材质库中检索并烘焙PBR贴图；部件模块利用PartVAE和PartDiT生成可编辑材质的语义部件网格，一次性解码多头部件特定的SDF场。每个模块均使用专用指标独立评估，既展示了当前系统的能力，也指出了迈向更广泛部署仍存在的差距。

## Abstract
We present Home3D 1.0, a modular image-to-3D generation system that produces high-quality 3D assets from a single reference image, targeting interior design and e-commerce applications. Given a photograph of a furniture or decor item, the system outputs a mesh with physically-based rendering (PBR) materials, and the mesh can be decomposed into material-specific components. The pipeline is organized into four tightly coupled modules: Geometry reconstructs a watertight mesh through latent SDF modelling with a geometry VAE and a coarse-to-fine flow-matching DiT; Texture predicts multiview albedo observations, reprojects them onto the mesh, and completes unseen surface regions with a 3D texture field; Material uses MatWeaver to obtain component masks through video-based segmentation and UV-space voting, then retrieves and bakes PBR maps from a curated material library through hierarchical multi-modal matching; and Parts generates material-editable semantic part meshes with a PartVAE and PartDiT, decoding multi-head part-specific SDF fields in one pass. Each module is evaluated independently with dedicated metrics, highlighting both the current system capability and the remaining gaps toward broader deployment.

### 2. 方法论：核心思想与关键技术细节

系统采用**四个顺序（或部分并行）的模块**，核心思想是将图像到 3D 生成分解为可控的子问题，避免单一模型的不确定性。

- **几何模块**
  - **核心思想**：通过**隐式 SDF（Signed Distance Field）** 和 **由粗到精的流匹配扩散变换器**生成水密网格。
  - **几何 VAE**：学习连续 3D 形状的紧凑隐空间。编码器采用感知器式的潜在查询机制，从采样点云（包含位置、法线、锐边指示）中聚合全局拓扑与局部细节信息。解码器根据隐向量预测任意查询点的 SDF 值，再用 Marching Cubes 提取网格。
  - **由粗到精的生成**：**粗阶段 DiT** 根据输入图像特征生成全局一致的形状隐向量；将其解码为初始网格并体素化，作为空间先验；**精阶段 DiT** 结合图像条件与空间先验，进一步细化局部结构、锐利边界与薄壁结构。
  - **训练**：VAE 使用 SDF 回归损失与 KL 散度；DiT 使用流匹配目标，并采用从大规模预训练到高质量微调的渐进训练策略，逐步增加隐令牌数量和图像分辨率。

- **纹理模块**
  - **核心目标**：从参考图像生成完整的表面反照率纹理。
  - **多视角反照率预测**：模型根据参考图像与几何信息，**联合生成多个规范视角的反照率图**，以保持视图一致性并减少原图光照影响。
  - **纹理补全**：将多视角反照率重投影到网格表面（产生不完整纹理），再通过 **3D 纹理场**（连续颜色场）直接预测不可见区域的表面颜色，避免 UV 岛接缝和不稳定性。
  - **训练**：结合扩散损失、一致性正则化、图像重建损失和梯度正则化，并引入光照增强以促进材质与光照的分离。

- **材质模块**
  - **核心思想**：不直接生成 PBR 贴图，而是从**精选材质库中检索并烘焙**高质量材质参数。
  - **MatWeaver 分割**：将 3D 网格的材质分解转化为**视频跟踪问题**。在多视角渲染序列中，用 SAM2 跟踪基于超像素和边缘采样生成的提示点，实现语义一致的全视分割；再通过 **UV 空间投影与投票**将 2D 分割标签映射回网格面片，获得干净的分区。
  - **分层多模态检索**：
    1.  精密对齐：用 RoMA+P4Pf 将 3D 部件投影到 2D 输入图上，生成局部组件掩码。
    2.  全局推理：VLM 为每个组件生成材质描述与类别。
    3.  跨模态嵌入检索：利用 Qwen3-VL 联合编码组件视觉特征与描述，在相应材质子类中检索 top-5 候选材料。
    4.  VLM 重排序：由冻结 VLM 担任专家裁判，从候选列表中选出最一致的材料。
  - **烘焙**：将选中的各组件 PBR 参数（金属度、粗糙度、法线等）**合并烘焙**为统一纹理图，并进行 Draco 压缩（尺寸可降低约 20 倍），产出可直接用于生产的资产。

- **部件模块**
  - **核心思想**：生成**材质可编辑的语义部件网格**，且采用**共享隐向量 + 多头 SDF 解码器**，避免按顺序逐个生成部件导致成本随部件数增长的问题。
  - **PartVAE**：编码器输入带部件 ID 的点云，通过部件感知的点交叉注意力输出一个**共享隐向量**；解码器将该隐向量一次性解码为 32 个单独的 SDF 通道，对应不同部件槽位，再用 Marching Cubes 提取各部件网格。
  - **PartDiT**：以 DINOv2 提取的参考图特征和完整形状的几何隐向量为条件，通过流匹配从噪声中生成部件隐向量。
  - **训练**：VAE 损失包括多头部重建损失、抑制非活动区域几何的抑制项及 KL 散度；DiT 采用大规模预训练、基于高质量渲染的继续训练以及人工筛选例子的监督微调三阶段。

### 6. 主要结论与发现

- Home3D 1.0 在**几何质量**上（CD=0.4936, EMD=5.174, F1=0.6329）领先于对比方法，特别是在输入图中不可见或弱可见的区域（如后背、内侧框架）结构更完整。
- 在**渲染外观**上，Home3D 1.0 取得了最优的 CLIP-I 和 LPIPS，定性上能更好地保留织物编织纹理、木纹、缝线等高频细节，并对毛绒、玻璃等特殊材质的表现更准确。
- **部件分解**方面，本系统的 PartVAE 通过共享隐向量与多头 SDF 解码，在生成语义部件的同时，避免了编解码时间随部件数显著增加的问题（与 PartCrafter 等相比有明显优势），且分解出的部件更符合材质编辑需求，支持组件级材质替换（如图 10）。
- 模块化设计被证明有效，各模块独立优化，能分别提升系统在不同维度的能力。

### 7. 优点

- **高度模块化**：将复杂的图像到 3D 任务拆解为可控的子问题，便于独立改进和排查失效原因。
- **生产级材质方案**：采用检索而非生成的方式获得 PBR 材质，大幅避免了直接生成材质贴图时常见的物理参数失准和模糊问题，并构建了层级分明、描述精细的材质库。
- **创新性的部件生成**：通过部件感知的共享隐空间和多头 SDF 解码，实现了**一次性解码所有部件**，解决了以往按部件顺序生成带来的计算开销和部件数量上限问题，且输出直接支持材质级别的编辑。
- **视频驱动的材质分割**：MatWeaver 将 3D 分割转化为视频跟踪问题，利用成熟视频模型（SAM2）和 UV 投票，无需人工标注即可获得干净的网格分区。
- **面向实际应用的优化**：考虑了资产压缩（Draco）、材质槽分配、PBR 烘焙等落地细节，使输出资产更具直接可用性。

### 8. 不足与局限

- **跨模块协同缺失**：模块间按顺序执行，缺乏反馈机制（如作者也指出未来可用材质预测指导几何简化），可能使上游误差向下游传播并放大。
- **评测规模与泛化性**：仅在一个 100 例的家具基准上评估，且真值来自设计师建模，基准多样性可能有限，能否泛化到更广泛的物体类别（如复杂灯具、装饰品）和真实用户实拍照片仍未可知。
- **部件模块独立性**：部件实验主要评估 VAE 自体重建能力，未报告在**完整流程中（结合图像输入与 DiT 生成）** 的部件质量定量结果，且表 2 中 PartVAE 的 CD 并非最优，表明重建精度存在一定妥协。
- **算力与训练细节未披露**：未说明模型训练所用算力，使其他研究者难以评估其复现成本和可行性。
- **依赖外部大模型**：材质检索和描述生成严重依赖多个 VLM（如 Qwen、Gemini），其性能会受到这些外部模型能力和更新的影响，也增加了系统的复杂性。
