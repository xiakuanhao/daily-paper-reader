## 摘要
我们提出了3D-DLP，一种自监督的、以物体为中心的表征学习模型，能够将场景级的RGB-D或体素观测分解为一组3D隐式粒子。基于深度隐式粒子（DLP）框架，每个粒子编码了可解耦的属性，包括3D关键点位置、边界框尺寸和外观特征，并代表场景中的一个独立实体。该模型通过端到端的自监督重构目标，学习可解释的逐粒子分割图。我们在模拟和真实世界数据集上证明，学习到的隐空间是可解释且可控的：通过操纵粒子位置并进行解码，我们可以生成新颖的场景配置。此外，我们展示了利用这些紧凑的3D隐式粒子进行下游机器人操作，相较于缺乏显式3D信息或依赖于不含物体中心结构的高内存密集3D输入的基线方法，性能有所提升。代码和视频可在https://eubooks3003.github.io/3d-dlp获取。

## Abstract
We introduce 3D-DLP, a self-supervised object-centric representation learning model that decomposes scene-level RGB-D or voxel observations into a set of 3D latent particles. Building on the Deep Latent Particles (DLP) framework, each particle encodes disentangled attributes, including 3D keypoint position, bounding box dimensions, and appearance features, and represents a distinct entity in the scene. The model learns interpretable per-particle segmentation maps through an end-to-end self-supervised reconstruction objective. We demonstrate on both simulated and real-world datasets that the learned latent space is interpretable and controllable: by manipulating particle positions and decoding, we can generate novel scene configurations. Furthermore, we show that leveraging these compact 3D latent particles for downstream robotic manipulation improves performance over baselines that either lack explicit 3D information or rely on memory-intensive dense 3D inputs without object-centric structure. Code and videos are available at https://eubooks3003.github.io/3d-dlp.

### 2. 论文提出的方法论

论文的核心是提出了 **3D-DLP （3D Deep Latent Particles）** 模型，将 2D DLP 框架扩展到 3D 输入。其核心思想是将场景分解为一组紧凑的 3D 隐式粒子，每个粒子代表一个独立的实体。

*   **统一的变分自编码器框架**：模型作为一个 VAE 进行训练，通过最大化证据下界来学习。
*   **三种输入模态变体**：
    *   **3D-DLP-D**：处理 **RGB-D** 图像。
    *   **3D-DLP-V**：处理 **占用体素** 网格。
    *   **3D-DLP-VC**：处理 **彩色RGB体素** 网格。
*   **粒子表征**：每个前景粒子 `z_m` 解耦为显式的 3D 属性：
    *   **位置 `z_p`**：3D 关键点坐标 `(z, y, x)`。
    *   **尺度 `z_s`**：3D 边界框尺寸。
    *   **透明度 `z_t`**：控制粒子的存在与否。
    *   **外观特征 `z_f`**：编码粒子周围局部区域的外观。
*   **核心架构（以 3D-DLP-VC 为例）**：
    1.  **先验模块**：为了解决体素稀疏性问题，提出了一种 **外观感知的 K-Means 关键点先验**。它结合体素在 CIELAB 颜色空间的颜色和 3D 位置，并利用亮度作为权重进行加权 K-Means 聚类，生成与物体表面和颜色边界对齐的 3D 关键点提案（`z̄_p`）。
    2.  **编码器**：利用 3D CNN 和 3D 空间变换网络，根据关键点提案提取局部体素块，并预测粒子属性的偏移（`Δz_p`）、尺度、透明度和外观特征。
    3.  **解码器**：将每个粒子的外观潜变量解码为一个规范空间的 RGBA 体素块，然后通过 3D 空间变换网络（STN）使用其位置和尺度属性放置回全局网格。
    4.  **体素合成**：通过归一化的 Alpha 通道加权平均合成前景物体的 RGB 颜色，再与解码后的背景 RGB 体素进行混合，实现最终的重构场景。
*   **关键损失函数**：
    *   **重构损失 `L_rec`**：结合均方误差（MSE）和一种**色度损失**（Chroma Loss），该损失仅在占据体素上惩罚色度（颜色饱和度/色调）误差，用以防止“灰色崩溃”问题。
    *   **KL 散度损失 `L_KL`**：约束粒子潜变量的后验分布靠近先验分布。
    *   **稀疏性正则化 `L_obj`**：鼓励使用更少的活跃粒子。

### 8. 不足与局限
