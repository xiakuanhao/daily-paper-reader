## 摘要
开放词汇三维功能分割使机器人能够在三维场景中定位功能性物体部件。这是一项需要空间理解与任务解读的挑战性任务。当前的开放词汇三维分割方法主要关注物体级识别，而场景级部件分割方法试图详尽分割整个场景，导致资源密集且耗时。在粒度、精度和速度之间取得分割性能的平衡仍是一大挑战。为缓解这一问题，我们提出 T-FunS3D，一种任务驱动的分层开放词汇三维功能分割方法，为机器人应用提供可操作的感知。该方法以室内场景的三维点云和位姿对齐的 RGB-D 图像作为输入，通过提取环境中的实例及其视觉嵌入构建开放词汇场景图。给定任务描述，T-FunS3D 识别场景图中最相关的实例，并借助视觉-语言模型定位其功能部件。在 SceneFun3D 数据集上的实验表明，T-FunS3D 在开放词汇三维功能分割方面与现有最优方法相当，同时运行时间更快、内存占用更低。

## Abstract
Open-vocabulary 3D functionality segmentation enables robots to localize functional object components in 3D scenes. It is a challenging task that requires spatial understanding and task interpretation. Current open-vocabulary 3D segmentation methods primarily focus on object-level recognition, while scene-wide part segmentation methods attempt to segment the entire scene exhaustively, making them highly resource-intensive and time consuming. Balancing segmentation performance in terms of granularity, accuracy, and speed remains a challenge. As one step towards alleviating this, we introduce T-FunS3D, a task-driven hierarchical open-vocabulary 3D functionality segmentation method that provides actionable perception for robotic applications. Our method takes as input the 3D point cloud and posed RGB-D images of an indoor scene. We construct an open-vocabulary scene graph by extracting instances and their visual embeddings in the environment. Given a task description, T-FunS3D identifies the most relevant instances in the scene graph and locates their functional components leveraging a vision-language model. Experiments on the SceneFun3D dataset demonstrate that T-FunS3D is comparable to state-of-the-art in open-vocabulary 3D functionality segmentation, while achieving faster runtime and reduced memory usage.

### 2. 论文提出的方法论
T-FunS3D 是一个无需训练的两阶段流水线方法，核心思想是 **“先建图，后按需查询”**。

*   **核心思想与流程**
    *   **第一阶段（场景预建图）**：对环境进行一次性的实例级理解和建模，构建一个“开放词汇场景图”，此阶段仅在场景不变时执行一次。
    *   **第二阶段（任务驱动查询）**：当收到一个具体的任务指令时，解析任务内容，在场景图中搜索并定位相关内容物体，然后仅对该物体进行功能部件的精细分割。

*   **关键技术细节**
    1.  **开放词汇实例分割**：利用Mask3D对点云生成类别无关的物体掩码，并从多视角RGB图像中为其裁剪区域和全图提取视觉语义嵌入（使用FG-CLIP），其中引入**带掩码的裁剪图**以减少背景干扰。
    2.  **开放词汇场景图构建**：将每个实例作为图节点，节点存储其多视角平均视觉嵌入。图的边由查询时动态计算，通过平均两个顶点关联的全图视觉嵌入来编码它们之间的语义和空间关系。
    3.  **大型语言模型任务理解**：使用大语言模型（Qwen3）解析自由形式任务描述，联合提取出**上下文物体（C）**、**参考物体（R）**、**功能部件（F）** 以及它们之间的**空间关系（S）**。
    4.  **上下文物体定位**：计算文本嵌入与所有图节点的视觉嵌入的余弦相似度，检索出C和R的候选节点。然后计算候选对之间的边嵌入与空间关系文本嵌入的相似度，选出最佳匹配的节点作为目标物体。
    5.  **功能部件分割**：仅取目标物体在最优视角下的RGB图像，使用视觉语言模型（Molmo）依据任务部件提示进行点定位，再以此提示分割模型（SAM）生成2D掩码，最后通过多视图聚合得到该部件的三维分割结果。

### 7. 优点
*   **高效的任务驱动设计**：创造性地将“全场景精细理解”转变为“建图+按需查询”，极大减少了冗余计算，使方法更贴近机器人实际应用需求。
*   **强大的开放词汇场景图**：场景图的边通过多视图视觉嵌入动态构建，隐式编码了实例间的空间和语义关系，提升了对复杂指代（如“床右侧的床头柜”）的理解和定位精度。
*   **无训练, 易升级**：整个流水线基于多个强大的预训练模型，无需任何训练数据微调。各个模块（如VLM、SAM）可以随着社区发展而灵活替换和升级。
*   **缓解前后景偏差**：在计算实例视觉特征时，创新性地引入带掩码的裁剪图，有效避免了因遮挡或背景（如窗外景色）导致的特征漂移。

### 8. 不足与局限
*   **级联误差**：流水线的多阶段设计可能导致误差从前序模块（如实例分割）向后续模块（如部件分割）累积。例如，若一个极小的物体（如电灯开关）在实例分割阶段被遗漏，则后续功能分割必然失败。
*   **对物理连接的依赖**：该方法假设功能部件与上下文物体有视觉上的物理依附关系。对于非物理连接的远程关系（如“天花板的灯”和“墙上的开关”）则难以处理。
*   **视角依赖性**：功能部件分割的质量高度依赖于所选相机视图。大倾斜视角可能导致掩码不准确，虽然投票机制有所缓解，但未根本解决。
*   **计算门槛**：尽管相对高效，方法仍依赖于大型语言模型和视觉语言模型，对机器人端的计算平台仍有较高要求。
*   **静态环境假设**：场景建图基于“环境物体空间关系基本不变”的假设，对动态变化频繁的环境适应性有限。
