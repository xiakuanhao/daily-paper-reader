## 摘要
从图像理解三维物体是机器人和AR/VR应用的基础。尽管近期工作在类别级姿态估计方面取得了进展，但现有的表示方法无法捕捉到推理物体部件、功能和交互所需的细粒度语义。在本工作中，我们研究相机空间中的类别级三维对应——从单张图像中预测出在类别内不同实例间保持一致的三维位置——并证明通过学习共享的可变形物体先验，这种对应可以在没有显式对应监督的情况下自然涌现。为了支持这一方向的研究，我们引入了HouseCorr3D，这是首个大规模单目类别级三维对应基准，包含50个家居物品类别的178k张图像、280个独特实例，以及直接在CAD模型上标注的三维关键点。关键的是，HouseCorr3D为遮挡区域提供了非模态对应标签和明确的对称性标注，解决了现有数据集的关键局限。我们进一步提出了Morpheus，一种通过解耦规范形状、形变和物体姿态来学习可变形类别级形状先验的方法。通过这种共享的规范基础，相机空间中具有语义意义的三维对应隐式地涌现出来。这些涌现的三维对应在HouseCorr3D上达到了新的最优性能，表明语义三维物体理解可以在没有直接对应监督的情况下实现。数据和代码已公开发布在https://github.com/GenIntel/HouseCorr3D。

## Abstract
Understanding 3D objects from images is fundamental to robotics and AR/VR applications. While recent work has made progress in category-level pose estimation, current representations fail to capture the fine-grained semantics needed for reasoning about object parts, functions, and interactions. In this work, we study category-level 3D correspondence in camera space -- predicting, from a single image, 3D locations that remain consistent across instances within a category -- and show that it can emerge without explicit correspondence supervision by learning a shared morphable object prior. To enable research in this direction, we introduce HouseCorr3D, the first large-scale benchmark for monocular category-level 3D correspondence with 178k images across 50 household object categories, 280 unique instances, and 3D keypoint annotations directly on CAD models. Crucially, HouseCorr3D provides amodal correspondence labels for occluded regions and explicit symmetry annotations, addressing key limitations of existing datasets. We further propose Morpheus, a method that learns morphable category-level shape priors by disentangling canonical shape, deformation, and object pose. Through this shared canonical grounding, semantically meaningful 3D correspondences in camera space emerge implicitly. These emerging 3D correspondences set a new state of the art on HouseCorr3D, demonstrating that semantic 3D object understanding can arise without direct correspondence supervision. Data and code are publicly available at https://github.com/GenIntel/HouseCorr3D.

- **核心思想与背景**  
  作者认为，通过让同一类别的所有实例共享一个可变形模板（可变形物体先验），三维语义对应可以**在没有显式对应监督的条件下自然涌现**。为此，论文同时构建了首个大型基准 **HouseCorr3D**，并提出了方法 **Morpheus**，以验证这一假设。

## 2. 方法论：Morpheus 的核心设计与关键技术细节

- **整体思路**  
  Morpheus 将同一类别所有物体视为一个共享规范网格的“身份保持变形”。模板网格的每个顶点拥有唯一标识，变形后仍保持语义身份，因此自然建立起跨实例的对应关系。三维对应预测被转换为**姿态与变形估计问题**。

- **可变形先验的构建**  
  - 采用混合体积-网格表示，通过符号距离函数（SDF）定义类别级规范形状，利用可微分行进四面体（Differentiable Marching Tetrahedra）提取网格。  
  - 学习一个仿射变形场 φ_a(v, l) = α(v, l) ⊙ v + δ(v, l)，其中 α, δ 由 MLP 根据顶点坐标 v 和实例潜码 l 输出，实现顶点级的位移。  
  - 潜码 l = ψ_l(I) 由基于 DINOv2 的变形编码器从输入图像提取。

- **对应预测流程**  
  1. 对查询图像和目标图像分别预测 6D 姿态（使用预训练扩散模型）和变形网格。  
  2. 将查询三维点投影到查询网格表面，获得网格面和重心坐标。  
  3. 利用共享拓扑，将重心坐标传递到目标网格，获得相机空间中的对应点。

- **训练损失**  
  训练分两阶段，均不使用关键点对应监督，仅通过几何一致性隐式涌现语义对应：  
  - 二维损失：非模态掩码的 MSE 和距离变换损失。  
  - 三维损失：变形网格顶点与真值网格的倒角距离。  
  - 正则化：Eikonal 损失保证 SDF 性质；变形 ℓ2 损失限制形变幅度；边缘平滑损失鼓励局部一致形变。  
  - 第一阶段优化几何损失，第二阶段加入变形正则化。

## 3. 实验设计

- **数据集与基准**  
  - **HouseCorr3D**：基于 Omni6DPose 合成子集构建，包含 50 类日常家居物品、280 个实例、178k 张图像。每类 2–19 个语义三维关键点直接标注在 CAD 网格上；提供非模态（含遮挡区域）标签和显式对称性处理（离散/连续对称）。标注采用双重标注、自动合并与手动验证流程，耗时约 65 小时。  
  - 额外测试：从 Omni6DPose 真实子集中筛选 5 个代表性类别（面包、面霜、吹风机、手提包、牙刷），手动过滤 13% 对齐错误帧，形成 24 个实例、134 个关键点的真实世界子集。

- **评估指标与设置**  
  - **PCK@0.1**：将三维欧氏距离归一化到物体三维包围框的最大边长，计算正确比例。  
  - 分为三种评估模式：二维像素空间、三维模态（仅可见点）、三维非模态（含被遮挡点），并支持对称性等值点容错。

- **对比方法**  
  - 二维特征匹配：DINOv2、NOCS（将规范化坐标作为特征匹配）、MagicPony 2D（投影规范坐标后匹配）。  
  - 三维空间匹配：GenPose++（利用 NOCS 空间和姿态执行点传递）、MagicPony（共享模板变形，但姿态与规范空间纠缠，需借助 GenPose++ 的平移和尺度）。

- **主要结果**  
  Morpheus 在二维、三维模态、三维非模态对应上全面优于所有基线。例如，3D 模态 PCK@0.1 达到 43.7，远高于 GenPose++（37.0）和 DINOv2（24.4）；非模态对应仍具有竞争力，相比模态仅小幅下降。真实子集上同样表现出良好的泛化能力。

## 6. 主要结论与发现

- 通过学习共享可变形物体先验，**无需任何三维对应监督**，即可在相机空间中预测出类别内语义一致的三维对应。  
- HouseCorr3D 基准首次为单目类别级三维对应提供了带非模态标签和对称性处理的评估平台。  
- 传统二维特征匹配或规范化物体空间方法无法有效解决此任务，而 Morpheus 通过解耦形状、变形和姿态获得了最优结果，并能在遮挡和对称情况下保持鲁棒。  
- 纯二维监督方法（如 MagicPony 2D）在三维空间中的对应预测并不可靠，即使在二维投影上看似合理。

## 7. 优点

- **任务创新性**：首次将类别级三维对应定义为相机空间中的任务，跳过了二维局限和规范化空间的语义不一致性。  
- **基准贡献**：HouseCorr3D 是一个规模大（178k 图像）、标注精细（非模态、对称性）的评估集，对推动该领域研究有重要价值。  
- **方法简洁有效**：Morpheus 仅用几何损失和姿态监督，无需对应标注，即能涌现语义对应；通过重心坐标传递的机制优雅且可导。  
- **泛化验证**：在真实场景子集上证明了合成数据训练的模型可以迁移。  
- **可复现性**：代码、数据、预训练权重全部开源，标注协议描述清晰。

## 8. 不足与局限

- **拓扑固定**：共享模板网格的连接关系不变，无法处理类别内的大拓扑变化（如部件数量的增减）。  
- **依赖姿态估计**：相机空间对应完全依赖预训练的 6D 姿态估计模块，姿态错误会直接导致对应混乱。  
- **细节过平滑**：变形正则化可能导致薄壁结构或尖锐特征被平滑，无法保留精细几何。  
- **数据局限性**：训练和主要评测均在合成数据上；真实子集经人工筛选且规模较小，真实世界鲁棒性仍需更多验证。  
- **变形能力有限**：对极端非刚体或大范围形状外推存在困难，部分细长部位可能无法充分变形。  
- **未探索更复杂的遮挡**：非模态评测虽能测试遮挡下的对应能力，但主要实验仍以合成场景为主，真实严重遮挡场景的可靠性未知。
