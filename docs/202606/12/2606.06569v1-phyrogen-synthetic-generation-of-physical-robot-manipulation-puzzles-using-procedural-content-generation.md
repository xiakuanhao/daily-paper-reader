## 摘要
机器人操作物理难题对于自动装配和拆卸任务非常重要。然而，要使机器人能够解决物理难题，需要学习操作技能，这需要大量的训练数据集，而生成这些数据集通常耗时且繁琐。为了克服这个问题，我们提出了物理机器人操作难题生成框架（PhyRoGen），它利用程序化内容生成（PCG）来自动生成操作难题的合成数据集。PhyRoGen是一个通用的难题生成器，可以生成具有互锁对象依赖关系的物理难题，其中必须先操作一个铰接物体，然后才能移动另一个。基于PhyRoGen，我们定义了六个具体的生成器，并用它们生成了24个物理难题。通过使用基准测试框架，我们能够使用基于采样的规划算法在1到300秒内解决所有难题。最后，我们通过在物理仿真中使用KUKA LBR iiwa机器人，证明了每个生成的难题都是可操作的。这表明我们的框架能够程序化地生成独特的、可解的机器人操作难题，这是基准测试操作算法和开发鲁棒基础模型的关键组成部分。

## Abstract
Robot manipulation of physical puzzles is important for automatic assembly and disassembly tasks. However, to enable robots to solve physical puzzles, manipulation skills need to be learned, which requires large training datasets, the generation of which is often time consuming and tedious. To overcome this problem, we propose the Physical Robot Manipulation Puzzle Generation framework (PhyRoGen), which leverages procedural content generation (PCG) for automated generation of synthetic datasets of manipulation puzzles. PhyRoGen is a general-purpose puzzle generator, which can generate physical puzzles with interlocking object dependencies, where one articulated object must be manipulated before another can be moved. Based upon PhyRoGen, we define six concrete generators which we use to generate 24 physical puzzles. By using a benchmarking framework, we are able to solve all puzzles in 1 to 300 seconds using sampling-based planning algorithms. Finally, we demonstrate that every generated puzzle is manipulatable by using a KUKA LBR iiwa robot in a physical simulation. This shows that our framework is able to procedurally generate unique, solvable robot manipulation puzzles, which is a crucial ingredient to benchmark manipulation algorithms and to develop robust foundation models.

## 2. 方法论

### 2.1 核心思想
将物理难题视为由运动链（kinematic chain）构成的场景，其中每个物体通过关节连接。生成难题的过程等价于构造满足互锁依赖的运动链，确保所有物体必须被依次操作才能解决最终目标（如移动绿色目标物体）。

### 2.2 关键技术细节

*   **PhyRoGen 生成器算法（Maker Algorithm）**：
    *   输入：物体、关节、变换的序列或集合，以及物体总数 N 和随机种子。
    *   迭代过程（见原文 Algorithm 1）：
        1. 初始化空运动链 K。
        2. 进行 N 次迭代，每次循环：
            - 根据种子从输入中抽取一个物体 `obj`、一个关节 `jnt` 和变换 `tf`。
            - 将该物体、关节附加到当前运动链 K 上，形成临时链 `Kt`。
            - 进行两次验证：
                *   先固定新关节为默认状态，使用 RRT-Connect 规划器检查是否可解（若能解，则说明该物体冗余，拒绝）。
                *   再让新关节可动，检查是否可解（若不可解，则拒绝）。
            - 通过验证后，用 `Kt` 更新 K，并跳出本次循环。
        3. 最终返回完整运动链 K。
    *   根据第一个物体的关节类型（棱柱、旋转、SE(2)）定义目标配置（如滑轨另一端、旋转90°、盒子外随机位置）。

*   **六种具体的运动链生成器**：
    不同的生成器通过提供不同的输入组合实现（见 Table I）：
    *   **Simple Sliders**：T 形滑块，仅含棱柱关节，变换为 0° 或 180°，物体数量为种子+1。
    *   **Continuous Space**：长方体，仅含旋转关节，随机平移和旋转。
    *   **Grid World**：长方体，含旋转和棱柱关节，变换为 0°、90°、180°、270°，物体数量固定。
    *   **Lockbox Random**：交替使用长方体和圆盘，交替使用棱柱和旋转关节，固定变换集合，7个物体。
    *   **Move N Times**：长方体与门/走廊元素，SE(2) 和棱柱关节，变换固定，需要多次重新抓取。
    *   **Rooms**：房间和门对象，固定关节，变换集合，4个物体。

*   **输出形式**：使用 Blender 和 Phobos 插件生成三维模型，并导出为 URDF 格式，同时可渲染图片。

### 2.3 难题求解与操作
*   **求解算法**：采用 LA-RRT（少动作 RRT）作为多物体规划器，在 Robowflex + OMPL 框架下寻找最少操作次数路径。
*   **机器人操作仿真**：
    *   使用 KUKA LBR iiwa 移动机械臂（3自由度底盘 + 7自由度手臂）。
    *   从 LA-RRT 最优路径中提取物体序列和路径。
    *   在抓取点计算逆运动学解，利用末端执行器雅可比矩阵生成关节运动方向。
    *   遇到奇异点时松手并重新抓取。
    *   连接抓取点间的运动使用 BIT* 规划器。
    *   仿真在 PyBullet 中进行。

## 6. 主要结论与发现

*   PhyRoGen 能快速生成具有互锁依赖关系的物理机器人难题（生成时间 4 秒至 83 秒）。
*   所有 24 个难题均可被基于采样的规划算法求解，LA-RRT 在 23/24 个场景中达到 100% 成功率，BIT* 在所有场景中达到 100%；解题时间在 1 秒至 300 秒不等。

*   所有生成的难题都能在仿真环境中由 KUKA 移动机械臂成功操作，实际执行与规划总时间在 4 秒至 51 秒之间。
*   该框架为机器人操作算法的基准测试和训练提供了可靠且可扩展的合成数据生成手段。

## 7. 优点

*   **首个针对互锁依赖难题的程序化生成框架**：填补了现有 PCG（如 ProcTHOR、MotionBenchMaker）无法生成需要推理物体间操作顺序的场景的空白。
*   **通用性强**：通过改变输入对象、关节和变换序列，可生成多种类型的难题，并可直接输出 URDF。
*   **保证可解性与可操作性**：生成过程中嵌入规划器验证，排除冗余或不可解的结构，最终所有难题均被成功操作。
*   **与规划器及仿真无缝集成**：使用标准的 OMPL、Robowflex、PyBullet 工具链，易于复现和扩展。
*   **速度快**：单个难题生成仅需数秒至数十秒，适合大规模数据集创建。

## 8. 不足与局限

*   **依赖链单一**：目前仅能生成顺序依赖（链式），无法生成多个物体独立阻塞同一目标等树状依赖结构。
*   **狭窄通路易失效**：当前方法难以生成含狭窄通道的环境，因为采样规划器往往处理不好此类情况。
*   **无在线难度调整**：生成过程是离线的，不能根据机器人学习进度动态调整难题难度。
*   **缺少与其他数据集的直接对比**：实验未对比 PhyRoGen 生成的数据和人工策划的基准在提升学习算法性能上的效果。
*   **无真实机器人验证**：全部操作实验仅在 PyBullet 仿真中完成，实物迁移未知。
*   **生成器种类有限**：仅展示了六种特定生成器，对更复杂或真实场景的泛化能力有待探索。
