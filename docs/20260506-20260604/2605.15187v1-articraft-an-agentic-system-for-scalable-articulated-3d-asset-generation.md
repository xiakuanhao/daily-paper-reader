## 摘要
理解关节式3D对象的一个瓶颈是缺乏大型且多样化的数据集。在本文中，我们提出利用大型语言模型（LLMs）来弥补这一差距，并大规模生成关节式资产。我们将生成关节式3D资产的问题简化为编写构建它的程序。然后，我们引入一个新的智能体系统Articraft，它可以自动编写此类程序。我们设计了一个程序化接口和框架，以帮助LLM有效地完成此任务。LLM针对一个领域特定SDK编写代码，用于定义部件、组合几何体、指定关节，并编写测试以验证生成的资产。该框架为LLM提供了一个受限的工作空间和接口，验证生成的资产，并返回结构化反馈。通过这种方式，LLM不会被诸如编写URDF文件或管理复杂软件环境等细节所干扰。我们证明，与最先进的关节资产生成器和通用编码代理相比，该方法能生成更高质量的资产。使用Articraft，我们构建了Articraft-10K，这是一个包含超过1万个关节资产的精选数据集，涵盖245个类别，并展示了其在训练关节资产模型以及在机器人仿真和虚拟现实等下游应用中的实用性。

## Abstract
A bottleneck in learning to understand articulated 3D objects is the lack of large and diverse datasets. In this paper, we propose to leverage large language models (LLMs) to close this gap and generate articulated assets at scale. We reduce the problem of generating an articulated 3D asset to that of writing a program that builds it. We then introduce a new agentic system, Articraft, that writes such programs automatically. We design a programmatic interface and harness to help the LLM do so effectively. The LLM writes code against a domain-specific SDK for defining parts, composing geometry, specifying joints, and writing tests to validate the resulting assets. The harness exposes a restricted workspace and interface to the LLM, validates the resulting assets, and returns structured feedback. In this way, the LLM is not distracted by details such as authoring a URDF file or managing a complex software environment. We show that this produces higher-quality assets than both state-of-the-art articulated-asset generators and general-purpose coding agents. Using Articraft, we build Articraft-10K, a curated dataset of over 10K articulated assets spanning 245 categories, and show its utility both for training models of articulated assets and in downstream applications such as robotics simulation and virtual reality.

- **整体含义（研究动机）**：为了弥补这一数据缺口，本文提出利用大型语言模型（LLMs）强大的编码与先验知识能力，自动、规模化地生成关节式3D资产。其核心思想是将复杂的3D资产生成任务简化为一个“编写程序来构建对象”的任务，通过设计一套专门的智能体（Agent）系统，使得LLM能够高效、低成本地完成此任务。

### 2. 论文提出的方法论
- **核心思想**：将关节式3D资产的生成过程，转化为由LLM驱动的智能体（Agent）迭代编写、执行和调试Python程序（`model.py`）的过程。该程序通过调用一个专门设计的SDK来定义部件、几何体、关节以及自检逻辑，最终输出包含网格、语义部件和URDF运动学结构的资产。
- **关键技术细节**：
    - **领域特定SDK（Programmatic Interface）**：为LLM提供一个封装了从低级几何图元（如圆柱体、长方体）到高级抽象（如合页、轮子）的Python API。LLM只需关注对象的结构化定义，而无需处理底层URDF文件编写或复杂软件环境。
    - **受限的智能体框架（Harness）**：这是一个任务专用的“编辑-执行-修复”循环环境。
        - **受限工作空间**：LLM只能编辑单一的`model.py`文件，SDK文档为只读，避免了通用编码智能体面对复杂文件系统时的“分心”。
        - **受限动作空间**：仅提供读取文件、编辑代码、查找示例、编译模型和探测几何体等少数关键工具。
        - **结构化反馈**：框架自动编译程序、执行基础质量检查（如零件漂浮、非正常穿透），并将结果以结构化的失败、警告、建议等形式返回给LLM，引导其迭代修复。
    - **自校验机制**：生成的`model.py`中包含`run_tests()`入口，允许LLM编写与对象特性紧密相关的特定几何约束和豁免声明（如“抽屉必须保持在滑轨内”），确保生成资产的物理合理性。
    - **基于图像的生成**：支持输入参考图像，智能体会以图像为主要真实性依据来生成几何体、比例和材质，并可结合外部工具恢复PBR材质。
- **算法流程**：给定一个自然语言描述，LLM智能体在框架内循环执行以下步骤：
    1. 读取当前`model.py`和SDK文档。
    2. 应用代码补丁修改对象定义。
    3. 触发编译模型，接收来自框架的结构化反馈（编译错误、QC失败警告等）。
    4. 可选地，通过探测工具获取精确的几何测量数据（如距离、间隙）。
    5. 根据反馈和探测结果，开始新一轮的编辑，直至所有检查通过。

### 3. 实验设计
- **评估场景与Benchmark**：
    - **生成质量对比**：为评估生成质量，构建了一个基于PartNet-Mobility数据集的46个类别的文本提示词基准集。采用用户调研的方式，比较不同方法在“提示词对齐度”和“整体质量”上的表现。
    - **数据有效性验证**：通过将生成的`Articraft-10K`数据集作为训练数据，增强现有模型“Particulate”，并在`Lightwheel`基准上进行评估，以验证其对下游任务的实用性。
    - **应用示范**：在NVIDIA Isaac Sim机器人仿真平台和虚拟现实环境中部署生成资产，验证其关节结构的有效性和交互可行性。
- **对比方法**：对比了四类具有代表性的关节资产生成方法：
    - `Articulate-Anything`
    - `PhysX-Anything`
    - `URDF-Anything+`
    - 通用编码智能体`Codex` (GPT-5.5)。
    - 本文方法自身也消融了不同底层LLM（GPT-5.5, GPT-5.4）和推理强度的影响。

### 4. 资源与算力
- **生成算力**：本文方法的一个核心设计原则是**轻量级**和**低成本**。生成过程**无需GPU**，仅需CPU即可完成本地的代码编译、CAD构建、网格生成和质检。昂贵的推理计算完全依赖外部的LLM API服务。论文提供了详尽的API成本统计：平均每个资产生成费用约为1.14美元，平均耗时约16.8个对话回合。这使得规模化生成在经济上可行。
- **训练算力**：对于展示数据集有效性的模型微调实验（Particulate），论文未明确提及使用的GPU型号、数量和训练时长。

### 5. 实验数量与充分性
- **实验数量**：
    - **1组主要的定性/用户评估**：对比了6种不同方法，收集了125名参与者对5000次比较的反馈。
    - **1组消融实验**：分析了不同LLM模型（GPT-5.5, Gemini, Claude）和不同推理强度对生成质量的影响。
    - **1组下游任务验证**：展示了数据增强对`Particulate`模型性能的提升。
    - **多组定量统计**：生成了超过1万个资产，并对保留率、API成本、对话轮次、几何复杂度等进行了全面统计。
- **实验充分性与公平性**：实验设计较为充分和客观。用户调研采用了随机化排序，确保了对比的公平性。对比的基线方法也覆盖了当时最先进的几种技术路线。通过下游任务的数据增强实验，有力地证明了生成数据的实际价值，而不仅是视觉上的美观。对失败案例的分析（如全局形状不佳、复杂机制难以表达）也体现了评估的全面性。

### 6. 论文的主要结论与发现
- 专门设计的领域SDK和受限框架是将LLM成功应用于复杂三维资产生成的关键，其效果远超直接使用通用编码智能体。
- `Articraft`系统能够以极低的成本（约$1.14/个）和轻量的资源（无需GPU）自动地生成高质量、物理上合理的关节式3D资产。
- 利用该系统成功构建了规模空前、类别丰富的`Articraft-10K`数据集，包含超过1万个资产和245个类别。
- 该数据集可有效用于训练下游3D关节估计模型，显著提升其在非训练类别上的泛化能力，并可直接应用于机器人和VR仿真。

### 7. 优点
- **创新性思路**：将复杂的3D资产生成巧妙地转化为LLM擅长的编程任务，并提供专用“编程语言”（SDK）和“编译器/调试器”（框架），思路新颖且有效。
- **轻量级与可扩展性**：完全避免了对渲染图像进行视觉反馈，无需GPU资源，成本低廉，使得大规模生成十万、百万级资产成为可能。
- **结构化与可解释性**：生成的资产不仅包括最终的3D网格和URDF，还包括完整的、可读的`model.py`源程序和详细的智能体推理与操作历史，具有很高的研究和工程价值。
- **强实用性验证**：不仅仅停留在生成数据本身，而是通过训练下游模型和部署到仿真环境，闭环验证了生成数据的质量和有效性。

### 8. 不足与局限
- **全局视觉质量依赖LLM**：验证过程侧重于结构和局部几何关系（不漂浮、无穿透），但全局形状的视觉合理性（如一个瓶子看起来是否像瓶子）仍然依赖LLM自身涌现的“常识”，缺乏显式的全局审美判断，可能导致一些形状畸变的失败案例通过结构检查。
- **复杂机制表达能力受限**：对于极其复杂或特殊的机械结构（如扳机式喷雾瓶），当前SDK可能难以被LLM直接构建和正确表达，运动范围也可能不准确。
- **人工审核仍然必要**：数据集最终发布前经过了大量的人工评分和筛选（保留率91.8%），说明完全自动化的质量保证仍有提升空间。
- **深层物理属性缺失**：虽然提供了运动学结构，但质量、阻尼等动力学属性是通过LLM“猜测”分配的，并非精确模拟，可能不适用于高精度的物理仿真任务。
- **应用门槛**：成本虽低，但依然依赖于商业LLM API，对于没有API预算的研究者来说，完全复现数据集生成可能存在障碍。
